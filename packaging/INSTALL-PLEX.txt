Arrs Hub — install notes (Plex PC + downloader PC)
==================================================

Ship artifacts on Google Drive\exe (same pattern as ytarr / Market Advisor):

1) START MENU INSTALLER (recommended)
   Arrs Hub-<ver>-x64.exe
   Arrs Hub Companion-<ver>-x64.exe
   - Per-user install → %LOCALAPPDATA%\Programs\…
   - Start Menu shortcut (+ optional Desktop)
   - Inno Setup wizard (lighter than old NSIS assisted flow)
   - Windows SmartScreen may warn on first run (unsigned unless you set
     ARRS_SIGN_PFX_PATH before publish — see README)

2) PORTABLE (quick test / no installer UI)
   Arrs Hub-<ver>-portable.exe
   Arrs Hub Companion-<ver>-portable.exe
   - Extract-and-run folder beside the exe
   - Good when upgrading in place on a machine that already trusts the app

Integrity / “verified” downloads
--------------------------------
Each publish writes Arrs Hub-<ver>-SHA256.txt (and Companion checksum file)
next to the exes on Drive. Compare before installing:

  Get-FileHash -Algorithm SHA256 ".\Arrs Hub-1.3.38-x64.exe"

Typical Plex layout
-------------------
- Plex PC: Arrs Hub (full stack, port watch, WOL relay)
- Downloader PC: Arrs Hub Companion (qBit/SAB restarts via hub)

Settings live under Electron userData\data — reinstall / upgrade keeps them.

What raises trust toward “Verified publisher” in Windows
-------------------------------------------------------
Authenticode code signing certificate (EV/OV) + timestamp server.
Optional: set ARRS_SIGN_PFX_PATH and ARRS_SIGN_PFX_PASSWORD, then
  npm run publish:exe
Unsigned builds are normal for ytarr / Market Advisor too — use checksums
and “Run anyway” on first SmartScreen prompt; later opens are faster.
