Arrs Hub — setup on your home / Plex PC
========================================

GOAL: run it like Sonarr/Radarr — click an icon, app window opens,
lives in the tray/taskbar. No need to leave a black Command Prompt open.


1) ONE-TIME DOWNLOADS (installers)
---------------------------------
A) Node.js LTS (required)
   https://nodejs.org
   - Windows LTS installer, defaults are fine (keep "Add to PATH")

B) Git for Windows (recommended for TRaSH / Recyclarr sync)
   https://git-scm.com/download/win


2) COPY THIS FOLDER
-------------------
Put the whole Arrs-Hub folder somewhere stable, e.g.:

   C:\Apps\Arrs-Hub

Keep the data\ folder — it already has Sonarr/Radarr API keys,
workout/Plex settings, and watchdog settings.


3) FIRST RUN (creates the real app experience)
----------------------------------------------
Double-click:

   Start Arrs Hub.vbs

   (or Start Arrs Hub.bat)

The first run may take a minute (npm install + UI build).
Then an Arrs Hub window opens. Closing the window keeps it running
in the system tray (near the clock). Right-click tray icon → Quit
to fully stop — same idea as Sonarr/Radarr.


4) DESKTOP ICON + START WITH WINDOWS
------------------------------------
Double-click once:

   install-startup.bat

That creates:
  - a Desktop shortcut "Arrs Hub"
  - a Startup entry so it launches when you sign in

To remove Startup later: uninstall-startup.bat


5) DAY-TO-DAY / RESTART AFTER QUIT
----------------------------------
Click the Desktop "Arrs Hub" icon (or Start Arrs Hub.vbs).

- Close the window  → hub stays in the system tray (near the clock)
- Double-click tray  → opens the window again
- Tray → Quit        → fully stops the hub
- After Quit         → double-click the Desktop icon (or Start Arrs Hub.vbs) to start again

Dashboard also available at: http://localhost:3000


WHY NOT A PLAIN .EXE / .MSI?
----------------------------
This wraps the hub in Electron so you get a normal window + tray icon.
You still need Node.js installed once (same as many modern tools).
A full single .msi is possible later, but this is the simple reliable path.


TROUBLESHOOTING
---------------
- "node is not recognized" → install Node.js LTS, reboot, try again
- Port in use → Start Arrs Hub.bat frees ports 3000/3847 automatically
- Blank/old UI → delete the dist\ folder and run Start Arrs Hub.bat again
- Settings missing → confirm data\ was copied with the project
- Icon looks wrong → run install-startup.bat again to refresh shortcuts
