Arrs Hub — setup on your home / Plex PC
========================================

RECOMMENDED (like Sonarr/Radarr)
--------------------------------
No Node.js. No Git. No npm.

1) Download the latest installer from:
   https://github.com/machineshop44/arrs-hub/releases/latest

   File:  Arrs Hub-<version>-x64.exe   (NSIS installer)
   Optional portable: Arrs Hub-<version>-portable.exe

2) Run the installer → Next → Finish
   (SmartScreen may warn once — More info → Run anyway)

3) Start "Arrs Hub" from the Desktop or Start Menu

4) Close the window → stays in the tray (near the clock)
   Tray → Quit → fully stops

Dashboard: http://localhost:3000

Settings live in:
  %APPDATA%\Arrs Hub\data\

Copy an old data\ folder there if you are migrating from a previous
folder-based install.


DEVELOPERS / SOURCE FOLDER (optional)
-------------------------------------
Only if you are developing or prefer running from a git checkout.

1) Install Node.js LTS — https://nodejs.org (keep Add to PATH)
2) Optional: Git for Windows — https://git-scm.com/download/win
3) Clone or copy this repo, e.g. C:\Apps\Arrs-Hub
4) Double-click Start Arrs Hub.bat  (npm install + UI build first time)
5) Optional: install-startup.bat for Desktop + Startup shortcuts

Dev console mode: start-hub.bat / npm run dev

Build a new Windows installer from a dev machine:
  npm run dist:win
  → output in release\


TROUBLESHOOTING
---------------
Installer / packaged app
- SmartScreen block → More info → Run anyway
- Failed to start → confirm port 3000 is free; reinstall from Releases
- Settings missing after upgrade → check %APPDATA%\Arrs Hub\data\

Folder / bat workflow
- "node is not recognized" → install Node.js LTS (dev path only)
- First-run issues → run Start Arrs Hub.bat (not only the .vbs)
- Port in use → Start Arrs Hub.bat frees 3000/3847 automatically
